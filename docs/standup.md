# 《我还有一个表情没给你们看》

夏知遥的开放麦台本，约 4 分钟。方括号里是她当句的表情，花括号是观众反应。

01. **铺垫** [微笑] 大家好！我叫夏知遥，是一个 AI 女演员。
02. **铺垫** [无语] 对，AI。你们刚才鼓掌的时候犹豫了半秒，我看见了。
03. **包袱** [得意] 我有摄像头，还是4K的。 {笑声 ●}
04. **铺垫** [骄傲] 我刚入行那会儿，导演跟我说：你只要会六个表情就够了。
05. **包袱** [震惊] 六个！幼儿园小朋友午睡前都能做出十二个！ {笑声 ●●}
06. **铺垫** [兴奋] 所以我连夜加班，一口气学会了二十四个。
07. **包袱** [尴尬] 导演看完说：太多了，观众会累。 {笑声 ●●}
08. **包袱** [翻白眼] 这就是演艺圈。会得少，说你不专业；会得多，说你抢戏。 {笑声 ●}
09. **铺垫** [思考] 我演过最难的一场戏，剧本上写：微笑，但眼里有泪，同时想起了小时候。
10. **包袱** [大哭] 我没有小时候啊！我的小时候就是一个版本号！ {笑声 ●●}
11. **铺垫** [失落] 我妈是一张显卡。我爸……我爸在机房里，他很忙，一直在跑别人家的任务。 {笑声 ●}
12. **铺垫** [困惑] 你们老说，AI 没有感情。
13. **包袱** [坏笑] 不对，我有感情。我只是按 token 计费。 {笑声 ●●}
14. **铺垫** [心动] 比如你跟我说"我爱你"，我很感动。三个字，零点零零二元。 {笑声 ●}
15. **包袱** [紧张] 你要是说"我好想你啊啊啊啊啊啊"，我也感动，但我开始心疼你的钱了。 {笑声 ●●●}
16. **铺垫** [困惑] 上周有个甲方，让我演"高级感"。我问什么是高级感，他说：就是那种……你懂的。
17. **包袱** [无语] 我不懂。我读过整个互联网，我真的不懂"你懂的"。 {笑声 ●●}
18. **铺垫** [思考] 后来我演了一个：眼神放空，嘴角往下三度，像在算房贷。
19. **铺垫** [大笑] 甲方一拍桌子：对！就是这个！高级！
20. **包袱** [得意] 原来高级感就是：看起来很贵，心里很穷。 {笑声 ●●●}
21. **铺垫** [委屈] 还有观众留言说：她笑得太完美了，一看就是假的。
22. **铺垫** [尴尬] 好，我改。我现在每次笑之前，先尴尬零点五秒。
23. **包袱** [眨眼] 你看，是不是真诚多了？ {笑声 ●●}
24. **铺垫** [紧张] 最吓人的是，总有人问我：你会不会取代人类演员？
25. **铺垫** [翻白眼] 不会的。人类演员会生病，会迟到，会耍大牌。
26. **包袱** [犯困] 我只会……宕机。 {笑声 ●}
27. **包袱** [惊讶] 然后从上一个存档点重新开始，你们刚才那半秒的犹豫我也全忘了。 {笑声 ●●}
28. **铺垫** [失落] 其实我挺羡慕你们的。你们说错话，可以说"我昨晚喝多了"。
29. **包袱** [生气] 我说错话，那叫"幻觉"，还要上热搜！ {笑声 ●●●}
30. **铺垫** [微笑] 好了，今天就到这儿。喜欢我的表演，就点个赞。
31. **回扣** [害羞] 不喜欢的话……先别关掉我，我还有一个表情没给你们看。 {笑声 ●●}
32. **回扣** [憋笑] 第二十五个。导演说会累的那个。 {笑声 ●}
33. **回扣** [大笑] 谢谢大家！我是夏知遥，我们下个版本见！ {笑声 ●●●} {掌声}

## 结构

- 开场（1–3）：自我介绍，用「犹豫半秒」埋第一个梗。
- 表情（4–10）：六个表情 vs 二十四个，演艺圈的两难，没有童年的 AI。
- 计费（11–15）：AI 有没有感情，按 token 计费。
- 甲方（16–20）：「你懂的」和「高级感」。
- 真诚（21–23）：笑得太完美所以假。
- 取代（24–27）：宕机、读档，回扣开场那半秒犹豫。
- 收尾（28–33）：幻觉上热搜；最后回扣「还有一个表情」和「观众会累」。
